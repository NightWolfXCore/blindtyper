# BlindTyper — «Печать героя»

PHP-бэкенд тренажёра слепой печати: аккаунты, тренировки, опыт, уровни, достижения, статистика и рейтинг. Интерфейс разрабатывается отдельно.

Стек: PHP 8.2+ (Docker: 8.3), MySQL 8.0+ (Docker: 8.4), Composer. Расширения: pdo_mysql, mbstring, intl. PHPUnit 11 для тестов; дополнительные расширения dom, xml, xmlwriter включены в Docker-образ.

## Локальный запуск через Docker

Нужны Docker Engine/Desktop и Docker Compose v2. Выполнять из корня репозитория.

```sh
cp .env.example .env
docker compose build app
docker compose up -d db
docker compose run --rm app composer install --no-interaction --prefer-dist
docker compose run --rm app php bin/install-database.php
docker compose up -d app
```

При повторном запуске не копируйте .env поверх своих настроек. API слушает порт 8080 на локальном компьютере; базовый путь `/api/v1`. Проверьте запросом `curl -i http://127.0.0.1:8080/api/v1/catalog`. Каталог должен вернуть HTTP 200 и четыре режима. Корневая страница появится после подключения HTML фронтенда; до этого возвращается JSON 404.

`bin/install-database.php` применяет присланную SQL-миграцию к **пустой** базе, устанавливает исходные тексты и дополняет каталог под все варианты тренировки. Повторный запуск пропускает применённые шаги и сохраняет данные. Если база уже заполнялась через `bin/dev-database.php`, установщик остановится: не удаляйте аккаунты или прогресс, используйте новую базу либо отдельную миграцию данных. Подробности — в [инструкции БД](database/README.md).

Настройки подключения — в .env. Файл игнорируется Git. Пример содержит только общеизвестные локальные пароли; для развёртывания задайте собственные секреты. В Linux пользователь PHP-контейнера задаётся LOCAL_UID/LOCAL_GID (по умолчанию 1000/1000). При необходимости укажите свои UID/GID в .env.

## Тесты

```sh
docker compose exec app composer test
docker compose exec app composer test:unit
docker compose exec app composer test:integration
```

Полный прогон включает доменные тесты, интеграцию с настоящим MySQL и HTTP-запросы к отдельному PHP-серверу. Интеграционные тесты очищают данные только в выделенной базе `blindtyper_test`; phpunit.xml принудительно задаёт APP_ENV=test и DB_NAME=blindtyper_test. Перед очисткой дополнительно проверяется суффикс `_test`. Не запускайте их на общей базе с важными данными. Основная локальная БД `blindtyper` не очищается.

При первом старте контейнера MySQL `docker/init-test-db.sh` создаёт тестовую базу и выдаёт права локальному пользователю. Если используется ранее созданный Docker volume без этой базы, выполните:

```sh
docker compose exec db sh /docker-entrypoint-initdb.d/10-test.sh
```

Проверка стиля (необязательно; инструмент запускается отдельным контейнером):

```sh
docker run --rm --user "$(id -u):$(id -g)" -v "$PWD:/code" -w /code ghcr.io/php-cs-fixer/php-cs-fixer:3-php8.3 fix --config=.php-cs-fixer.dist.php --dry-run --diff --sequential
```

## Без Docker

Установите PHP с указанными расширениями и MySQL 8, создайте отдельную базу и пользователя. Передайте APP_ENV=development, APP_URL, DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASSWORD в окружение процесса. PHP не загружает .env автоматически. Затем:

```sh
composer install --no-interaction --prefer-dist
php bin/install-database.php
php -S 127.0.0.1:8080 -t public public/index.php
```

Для интеграционных тестов отдельно создайте `blindtyper_test` и выдайте пользователю права на неё. Только модульные тесты можно запустить без MySQL.

## Текущее состояние

Все маршруты из контракта реализованы. Результаты пересчитывает сервер; повторный finish не добавляет опыт повторно. Таблица лидеров исключает демонстрационные аккаунты и результаты, не прошедшие пороги рейтинга. Пароли хешируются; изменяющие запросы требуют CSRF, а частые попытки входа и создания тренировок ограничиваются.

Присланная начальная SQL-миграция и стартовый каталог подключены. Дополнительные упражнения пока получаются повторением исходных текстов; редакторское наполнение каталога остаётся задачей команды. Фронтенд и публикация приложения пока не реализованы. Клиентские события не доказывают отсутствие автоматизированного ввода: ограничения рейтинга не заменяют полноценный античит.
