# Что исправлено при подключении базы данных

Присланные `database/migrations/0001_initial.sql` и `database/seeds/0001_initial_data.sql` совместимы по именам таблиц и полей с PHP-бэкендом. При включении их в запуск проекта потребовались следующие исправления:

1. Добавлен `bin/install-database.php`: на пустой базе он применяет миграцию, записывает её версию в `schema_migrations`, а затем устанавливает seed. Повторное применение пропускает выполненные шаги. Существующую базу без метки миграции он не меняет.
2. У исходных упражнений `text_length` был указан вручную. При установке он пересчитывается по фактическому числу Unicode-символов, чтобы выбор упражнения по длине работал корректно.
3. В 30 исходных текстах не было полного набора длин 120/240/1200 для всех параметров API. Установщик добавляет варианты из исходных текстов, в том числе длинные упражнения для достижения за серию из 1000 символов. Исходные упражнения `words` со словами длиннее разрешённых 10 букв отключаются; дополнительные варианты используют подходящие слова.
4. Удалён `config/database.php`: это были строки настройки, хотя файл назывался PHP, и приложение его не читало. Подключение уже задаётся переменными окружения; для Docker есть `.env.example`.
5. Seed с фиксированными ID применяется только к пустому каталогу. Автоматическое наложение на базу, созданную через `bin/dev-database.php`, могло бы смешать разные упражнения с одинаковыми ID и повредить ссылки истории тренировок.

Тексты дополнительных упражнений пока однообразны, потому что строятся из коротких образцов. Для уже заполненной локальной базы перенос данных нужно спроектировать отдельно. Подробности запуска — в [инструкции БД](../database/README.md).
